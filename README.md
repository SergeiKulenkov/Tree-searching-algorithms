# Tree-searching-algorithms

A compilation of tree searching algorithms:
* Insert and Delete node for a binary search tree
* Depth first (iterative and recursive) traversal
* Breadth first with and without layers traversal
* Inorder, Preorder and Postorder traversals
* TreeIncludes and BSTIncludes
* TreeSum - using recursive DFS sums up all nodes' values in a given tree
* TreeMinValue (iterative and recursive) - using DFS finds the minimum value in a given tree
* TreeMaxPathSum - gets the maximum path length from values in a given tree
* MaxDepth - recursively calculates max depth of a given tree
* IsSameTree - checks if two trees are identical
* GetInvertedTree - swaps left and right subtrees of every node
* GetRightSideView - returns a vector with the right side view
* ValidateBST
* Construct - builds a binary tree from provided inorder and preorder traversals
